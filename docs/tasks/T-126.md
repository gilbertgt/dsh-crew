## 要做什么

`qa/` 是从 `docs/qa/` 复制来的，但内部的相对路径是按 `docs/qa/` 深度写的。改成 `qa/` 深度：
- `qa/lib/qa.mjs` 的 `REPO` 常量：`resolve(..., "..","..","..")` 从 `<repo>/docs/qa/lib` 上 3 层到 repo 根；在 `<repo>/qa/lib` 上 3 层**指向仓库外**——改成上 2 层。`tempRepo()` 拷贝清单里 `docs/qa` 相关路径改 `qa`。
- `qa/run-all.sh` 的 `find "$here"` 起点（$here 跟随脚本位置，无需改 find 本身，但确认）。
- `qa/gaps.md`、`qa/README.md`、`qa/rule-guard-map.md` 内部对 `docs/qa/` 的引用改 `qa/`。
